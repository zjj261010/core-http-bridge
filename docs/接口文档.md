# core-http-bridge 接口文档

## 1. 文档信息
- **项目/服务**：core-http-bridge（CORE 网络仿真器 HTTP 管理平台 + 靶标管理系统）
- **版本/分支**：main @ ea9637f（管理平台 2.0）
- **文档来源**：OpenAPI 3.1 schema（`/openapi.json`，FastAPI 自动生成）+ 源码 `app.py` / `target_admin.py` / `platform_db.py` / `bridge.py` + 本轮实测记录（CLAUDE.md 各任务验证）
- **Base URL**：`http://<服务器IP>:8080`（本机 `http://localhost:8080`；公网 `http://112.124.17.97:8080`）
- **生成日期**：2026-11-16
- **适用范围**：CORE 会话管控（会话/节点/链路/服务/EMANE/无线/移动性/流式）、靶标管理（镜像三件套/实例/独立容器/导入事务模型）、监测（host/容器/指标/事件查询）、审计、演练身份、预检
- **已知限制**：
  - 无鉴权（内网平台定位，RBAC 已裁撤）
  - docker stats 的 NetIO 对 `--net=none` 容器恒为 0B（CORE 注网方式所致，监测页已改读容器内计数器）
  - `DefaultRoute` 内置服务对 docker 节点存在手册 §9 已知限制（本环境 WORKDIR=/ 修复后实测可用）
  - 4 个 WebSocket 端点不入 OpenAPI（FastAPI 原生不支持），文档单独列出
  - `/api/execute` 为调试用 Python 脚本执行端点（CoreEmu 上下文），生产部署建议关闭

## 2. 通用约定
- **协议与编码**：HTTP/1.1，UTF-8；SSE 端点 `text/event-stream`；上传端点 raw 字节流
- **认证方式与请求头**：无鉴权。无需任何令牌/请求头（除 Content-Type）
- **通用请求头**：`Content-Type: application/json`（有 JSON Body 时）
- **通用响应结构**：两族
  - **CORE 原生族**（`/api/*`）：返回 CORE gRPC 对象的 JSON 序列化（会话/节点/链路等原生结构）
  - **靶标管理族**（`/targets/*`、`/instances/*`、`/containers/standalone*`、`/monitor/*`、`/audit`、`/drills`、`/events`、`/metrics`、`/precheck`）：统一 `{"ok": bool, "data": {...}}` / `{"ok": false, "error": {"code", "message", ...}}`
- **时间/日期格式**：`YYYY-MM-DD HH:MM:SS`（platform_db 审计/事件/指标）；镜像 CreatedAt 为 docker 原生格式
- **分页约定**：`limit` 查询参数（audit/metrics/events 默认 100~500，drills 默认 200）；无游标分页
- **幂等性说明**：GET/DELETE 幂等；POST 创建类非幂等（重复创建同名校验拒绝）；PUT/PATCH 更新幂等
- **限流/超时说明**：无专门限流；上传上限 20GB；流式端点长连接（前端 EventSource/WebSocket）
- **错误响应统一格式**：
  - 靶标管理族：`{"ok": false, "error": {"code": "<错误码>", "message": "<中文描述>", ...附加字段}}`
  - CORE 原生族：FastAPI HTTPException `{"detail": "<描述>"}` 或 gRPC 异常透传 `{"detail": "gRPC status: ..."}`
  - 校验失败：FastAPI 422 `{"detail": [{loc, msg, type}, ...]}`

### 4.1 Get Config

- **方法 + 路径**：`GET /api/config`
- **用途**：获取系统全局配置（可用服务列表 + EMANE 模型列表）
- **认证要求**：无（内网平台，无鉴权中间件）
- **幂等性/限流/超时**：无专门限流；uvicorn 默认超时；流式端点长连接
- **请求头**：`Content-Type: application/json`（有 Body 时）
- **路径参数**：
无
- **查询参数**：
无
- **Body 参数**：
无（`/targets/import/upload` 与 `/targets/import/bundle/upload` 为 raw 流式字节上传）
- **请求示例**：

```bash
curl -s http://localhost:8080/api/config
```
- **成功响应状态码**：200（POST 创建类 201）
- **成功响应字段说明**：与 Body 参数结构同源（OpenAPI `/openapi.json` 响应 schema）；靶标管理族通用形态 `{"ok": bool, "data": {...}}`

- **失败响应状态码与错误码**：400/404/409/413/500；靶标管理族 `{"ok": false, "error": {"code": "...", "message": "..."}}`，错误码见第 5 节汇总
