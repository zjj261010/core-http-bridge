## 操作路径和已完成结果

共记录 56 步，54 步操作执行完成、2 步未完成。这个数字表示操作执行结果，不代表 54 个产品验收项全部通过；途中观察到的问题单独列在下方。

1. 首页 → 镜像管理 → 导入/取消 → 本机上传镜像 tar，等待任务完成并自动打开详情。
2. 新增 HTTP 服务及端口 → 新增/取消启动模式 → 上传启动、就绪检查和停止脚本 → 新增手动维护模式 → 暂存回镜像 → 最后确认并生效。
3. 导出配置和脚本 ZIP → 在镜像中暂存说明后切换模块 → 创建 Docker 模板、复制模板、创建原生模板。
4. 新建拓扑 → 选择指定模板 → 覆盖模式并恢复默认 → 添加原生客户端与交换机 → 拖动节点 → 连线/取消/重复连线 → 点线修改 IP、带宽和时延 → 保存重开。
5. 启动先取消再确认 → 同工作区查看实际运行 → 点击节点寻找终端/命令 → 检查联通，Docker 与原生节点双向 ICMP 均可达。
6. 进入监测 → 选择会话 → 订阅真实 CPU/流量/事件 → 查询历史指标 → 运行中修改镜像说明并仅保存待生效 → 返回确认原拓扑仍运行。
7. 新建独立容器 → 命令栏 Enter 执行，返回 `human-ui-ok` → 打开独立容器终端，返回 `terminal-ui-ok` → 停止/启动 → 删除先取消再确认 → 审计中查询到命令记录。
8. 停止拓扑 → 通过编辑下次配置再次启动 → 导出实际拓扑 → 删除当前会话及历史中的旧停止会话 → 删除保存配置 → 查看历史 → 复制并尝试另存。
9. 会话结束后回到镜像使待生效配置生效 → 后台导出完整包并实际下载 45,137,148 字节 → 导入配置 ZIP 查看冲突预览并取消 → 返回历史列表。
