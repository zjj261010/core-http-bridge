## 改造范围

依据参考项目的 `src/index.css`、`Layout.tsx`、`ui.tsx` 和拓扑组件，统一深色分组侧栏、浅灰工作区、白色卡片、青色强调色、胶囊按钮、圆角输入框和浅色状态标签。沿用现有 API 和功能入口，未迁入参考仓库的演示数据或模拟终端。

- `static/workbench.css` 提供共用配色、字体、间距、表格、弹窗、抽屉和响应式布局；`workbench.js` 提供移动导航与独立页面导航整理，无外部 CDN 或构建依赖。
- 主工作台按资源管理、环境构建、运行与复盘分组；顶部显示当前视图和真实连接状态。会话及运行操作在拓扑视图中展示；窄屏使用可关闭的导航抽屉。
- 镜像、容器、节点模板、监测、审计五个管理页统一页头和数据表样式；移除不适合产品界面的内部实现说明。节点模板分类改为选中态明确的胶囊切换，并修正原来表头与表体分属两个表格的结构。
- 版本发布和拓扑草稿页面改为“草稿列表 + 编辑区 + 操作栏”。保留全部原有元素 ID、草稿保存、版本引用、差异确认、发布、下载与部署入口。模板列表为空时不再请求空名称的版本 URL。
- 拓扑画布改用浅色网格、白色节点与线性图标；节点点击、拖拽、链路及版本逻辑保留。两种真实终端使用统一的深色输出区和控制条，WebSocket 与 PTY 处理不变。
